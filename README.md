## GitHub Pages

This site is intentionally dependency-free: `index.html` + `styles.css`. That keeps the public portfolio fast, maintainable and easy to host on GitHub Pages.

To publish, open **Settings → Pages** and choose **Deploy from a branch**, then select `main` and `/ (root)`.
